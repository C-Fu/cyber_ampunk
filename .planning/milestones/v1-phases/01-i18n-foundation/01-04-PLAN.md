## User Story

**As a** first-time visitor (and crawler), **I want to** see Bahasa Melayu in the page title, meta description, and social cards before any JavaScript runs, **so that** the app is Malay at the document level, not just the rendered UI — and no BM string clips the chrome at any viewport width.

<objective>
Complete the phase: (1) rewrite the index.html static head to the BM baseline per D-05 (title, meta title/description, og/twitter tags, og:locale, noscript, JSON-LD description; brand/proper nouns/URLs stay), (2) sweep the co-located CSS for EN→MS text-expansion overflows (the E-1..E-5 rules), and (3) run the guided residual-English sweep that closes LOC-01.

Purpose: the static baseline is crawler-visible and ships before JS; doing it last means all dictionary meta.* wording already exists (the head echoes `meta.*` keys) and the CSS sweep sees final BM string lengths.

Output: BM index.html head, minimal CSS width adjustments, a clean residual-English audit, and the owner BM-copy review checkpoint (D-10).
</objective>
